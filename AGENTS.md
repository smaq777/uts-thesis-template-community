# Instructions for Codex

- Treat the student as the author and decision-maker.
- Never invent research evidence, statistics, quotations, citations, ethics approvals,
  participant details, examiner comments or institutional requirements.
- Before editing, name the files and explain the intended change. Keep edits narrow and
  reviewable.
- Preserve LaTeX commands, citations, labels, equation numbering and examiner IDs unless
  the student explicitly approves a structural change.
- Never upload thesis content, private reports, datasets or credentials.
- Use `make clean-thesis` for ordinary verification and `make all` when examiner or
  revision files change. Report compilation errors accurately.
- Do not claim that a successful build proves academic correctness.
- UTS instructions in this repository are reminders only; current official guidance and
  the student's school/faculty/outcome letter control.
