# Contributing

Thank you for helping future thesis writers. Use a GitHub issue before a substantial
change, explain the student problem being solved, and keep examples synthetic.

A contribution should:

1. preserve the unofficial, institution-neutral default and distribute no university logo;
2. retain attribution and the applicable licence notices;
3. avoid personal, confidential, copyrighted or research-restricted content;
4. update student documentation when behaviour changes;
5. run `make all` and visually inspect affected PDFs; and
6. link current official sources for policy-dependent claims and include a checked date.

Do not submit real examiner reports, outcome letters, participant material or unpublished
thesis content in an issue or pull request. Describe a synthetic reproduction instead.
