# AI-use records

UTS graduate research students should document generative-AI use throughout the
research project rather than trying to reconstruct it immediately before submission.

1. Copy `ai-use-log.example.csv` to `ai-use-log.csv`.
2. Add one row for each materially distinct use or repeated workflow.
3. Record the affected chapter/file, usage category, tool/model/version, platform, date,
   purpose, prompt-record location, output incorporation, verification and data class.
4. Store full prompts, outputs or screenshots only in an institution-approved secure
   location. The CSV can contain a durable reference to that record.
5. Summarise the completed log truthfully in the Certificate of Original Authorship and
   its required declaration table.

`ai-use-log.csv` is ignored by Git because it may reveal private research context. The
example CSV is synthetic and safe to publish. A student may deliberately version a
sanitised log in a private repository after checking university, ethics, confidentiality,
data-classification and intellectual-property requirements.

The fields are intentionally more detailed than the final declaration table. They help
the student demonstrate what happened, where it happened, how the output was checked,
and who remained responsible.
